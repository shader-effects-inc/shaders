# Security

If you find a security problem in the engine, a component, or the `shaders` package, email simon@shaders.com. Don't open a public issue for it.

Include what you found, how to reproduce it, and the version you tested. You'll get a reply from that address, and a fix will ship as a normal release once it's ready, with credit in the changelog if you want it.

Problems with shaders.com itself (the design editor, accounts, billing) go to the same address.
